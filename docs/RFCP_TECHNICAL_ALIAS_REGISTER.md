# RFCP retained technical aliases

The current product identity is Registered Federal Contractors Portal (RFCP). Federal and State/local opportunity discovery are one contractor experience.

The following historical identifiers remain only to preserve deployed integrations and database compatibility:

- Netlify site name `national-gov-contract-center`.
- Source files, API functions, browser-storage keys, environment variables, tables, and operational evidence fields prefixed `ngcc` or `NGCC_`.
- Existing `capgen_*` database tables and `capgen_session` browser-storage key.
- State inventory fields prefixed `natcorp_`.
- Analyze Fit ledger `product_code='ngcc'`.

These identifiers must not be rendered as separate current products. Renaming them requires a separately reviewed compatibility migration.
